# Competências demonstradas e próximos aprendizados

[Índice](README.md)

Esta página mapeia evidências do repositório. Não afirma experiência profissional, certificações ou autoria individual de cada trecho recuperado.

| Competência | Evidência concreta | Limite / próximo aprendizado |
| --- | --- | --- |
| Python e regras de negócio | Protótipo inicial, `services.py`, validação e `Decimal` em `utils.py` | Diminuir duplicação quando houver necessidade concreta |
| Flask e Jinja | Rotas/formulários em `app.py`, layout compartilhado e 15 templates | Autenticação, CSRF e consistência dos erros |
| HTML e CSS | Templates e `static/css/style.css`, temas e layout adaptável | Verificação de teclado, contraste e tablet |
| JavaScript puro | `static/js/main.js`: tema, menu, confirmação e troco | Testes reais de interação no navegador |
| Modelagem SQL | Nove tabelas, FKs, `CHECK`, índices, colunas geradas e sete views | Migrations e evolução com dados existentes |
| Integração MySQL | Conector, queries parametrizadas, snapshots, commit/rollback | Protocolo de bloqueio sob concorrência |
| Figma | Frames low-fi/hi-fi, identidade, estados e reações inspecionadas | Completar fluxos de caixa e validar experiência com usuários |
| Testes | `unittest`, teste Flask, 12 testes de integração real e seis históricos | Concorrência, acessibilidade e regressões com dados históricos |
| Git e manutenção | História preservada, branch de consolidação, commits focados e PR | Revisão humana e aceitação das entregas |
| Gestão e escrita técnica | Issues com critérios, roadmap, matriz de evidências e guias | Aplicar configuração pendente no Projects e manter evidências atualizadas |

As tecnologias fora da stack encontradas em uma versão anterior de interface não são apresentadas como competências desta implementação Flask. O [roadmap](../ROADMAP.md) relaciona os aprendizados necessários às próximas entregas.
